# Expense Tracker 💰

A web-based Expense Tracker application built using **Python Django** that helps users manage their income and expenses efficiently.

## Features 🚀

- User Registration and Login Authentication
- Add Income and Expense Transactions
- Edit and Delete Transactions
- Search Transactions
- Filter Transactions by Date
- Export Transactions as CSV
- Dashboard with:
  - Total Income
  - Total Expense
  - Balance Summary
  - Expense Analysis
- User Profile Management
- Responsive UI Design

## Technologies Used 🛠️

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite Database
